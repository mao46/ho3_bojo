為 禾山部長商家合作製作的 商家網站專案，展示了完整的前端靜態頁面，包括首頁、商品頁、購物車、結帳流程、關於我們等內容。
（此專案主要使用 HTML、CSS、JavaScript 實作前端頁面）📦  ￼
透過UI/UX設計 優化網站
⸻

📌 專案簡介

ho3_bojo 是一個商家購物網站的前端範例，內容包含：
 首頁（index.html）
 商品清單頁（allproduct.html）
 分類商品頁（如 dress.html、outer.html）
 購物車 & 結帳流程（cart.html、checkout.html）
 資訊頁 & 幫助頁（information.html、help.html）
 關於我們（about.html）
 其他共用元件（top.html、bottom.html、share.html 等）
 CSS 樣式（styles.css, animations.css, allproduct.css）
 JavaScript 互動（script.js）
 圖片素材資料夾（cloth_img/, image/）  ￼

⸻

🧩 技術棧

此專案採用：
	•	HTML5 — 網頁結構
	•	CSS3 — 版面樣式與動畫
	•	JavaScript — 前端互動功能
